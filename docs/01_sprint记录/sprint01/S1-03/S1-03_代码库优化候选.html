当前执行面

自动门禁关闭、空选择、非 playing 或错误盘面在调用能力前返回，零 solver。
技巧固定点只扫描勾选集合；每轮一份 mask 快照，首个成功后数值差分，失败技巧之间零 Python 候选投影。
完整结果最终候选和 notes 各一次，Game 直接接收同轮结果，保留撤回与累计删除 owner。
能力分开自动零 LogicStep；metadata 零最终 notes；Hint 一次 next_step。single / auto / diff 在实际分支加载。
异常 / 无变化能力异常保留 Game 状态；无变化不增加撤回记录，也不更新消息或完成状态。

为什么保持当前分工

自动 module 隐藏候选与执行知识，形成 depth 与 locality；结果 interface 供产品和测试跨越同一 seam，形成 leverage。Game 继续拥有游戏状态应用，真实 CLI / legacy adapter 保持兼容用途。

Deletion test：移除完整结果或内部差分会让调用方重新理解可变 solver 与候选时序。结果 board / notes 已转交单一所有权，额外深复制或通用 adapter 没有实际业务依据。
