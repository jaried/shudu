## Depth、locality 与 deletion test

公开 Module 将原散落实现放在同一知识归属中，根 adapter 仅保留现有启动和兼容行为。维护技巧与候选时可在目录内定位实现，形成 locality；现有调用方和回归从同一公开 interface 使用实现，保留 leverage。

删除根 adapter 会把真实 CLI 和历史导入兼容知识移到调用方，并损失已验证行为。将 `_engine`、`_project`、`_results` 再合并成单文件只改变文件布局，不能证明提高 depth。当前真实 adapter 足够支撑既有 seam，没有新增一层抽象的依据。

步骤事实的产生、技巧身份、按需导入与完整自动结果已在 S1-02/S1-03 批准范围。它们是继续推进的工作，本报告保持该分工，候选列表为空。
