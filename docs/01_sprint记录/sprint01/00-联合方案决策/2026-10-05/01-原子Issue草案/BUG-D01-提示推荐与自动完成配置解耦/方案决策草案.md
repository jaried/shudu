## 1. objective

让“提示”成为独立的推荐 capability：基于当前正式棋盘，按项目支持的全部逻辑算法稳定顺序寻找下一条可解释步骤；自动解决菜单的勾选集合只控制自动执行。

关卡 119 的核心验收：

- 默认自动配置未勾选 Hidden Pair 时，提示仍返回 Hidden Pair；
- 自动算法全部关闭时，提示仍返回 Hidden Pair；
- 该 Hidden Pair 是第 6 行的 3/6：R6C2 / R6C7，删除 R6C2 的候选 7。

## 2. 事实与根因

现有调用链：

```text
Game.hint()
  -> make_hint(board, notes, wrong)
  -> pending_step(board, notes)
  -> ShuduSolver.next_step()
  -> already_noted(step, notes)
```

`next_step()` 本身使用全部逻辑算法；问题发生在 `already_noted()` 对可见 `Game.notes` 的解释。

`Game.notes` 同时承载：

- screenshot 导入候选；
- 玩家手工笔记；
- 自动算法最终候选投影；
- 自动笔记结果。

因此它不是稳定的“推荐进度”真源。自动算法配置触发候选重算后能够改变 `notes`，进而改变推荐结果。

## 3. Module / Interface / Seam / Adapter / 文件布局

### Module：ShuduSolver

**Interface**

`next_step() -> LogicStep | None`

合同：

- 使用全部支持的逻辑算法；
- 固定顺序：Hidden Single → Naked Single → Naked Pair → Hidden Pair → Naked Triple → Pointing Pair → Box-Line Reduction → X-Wing → XY-Wing；
- 返回第一条逻辑步骤；
- 不读取 `UserSettings.auto_techniques`；
- 不读取可见 notes；
- 不进入回溯。

### Module：Hint

**Interface**

根据最终 grilling 分支选择：

- 分支 B：`make_hint(board, wrong) -> Hint`
- 分支 A：`make_hint(board, wrong, auto_eliminations, manual_eliminations) -> Hint` 或等价最小结构化输入；visible notes 不进入 Interface。

**Seam**

`Game.hint()` -> Hint Module -> `ShuduSolver.next_step()`

**Adapter**

`shudu/sudoku_hints.py` 继续承担 `LogicStep -> Hint`；没有第二个实现，不新增 Adapter 注册表。

## 4. 业务行为

共同语义：

1. 提示只读。
2. wrong cells 优先返回错误提示。
3. 正常盘面由项目 solver 使用全部逻辑算法找下一步。
4. 自动解决只消费用户勾选集合。
5. 自动配置持久化继续只服务自动执行。
6. 自动完成真实改变正式棋盘后，后续提示允许随新棋盘改变。
7. 提示不使用回溯答案。

### 分支 A：保留玩家手工消除推进

- screenshot notes 不作为“已经完成”的证据；
- 自动候选投影不作为玩家进度；
- 只有玩家在本应用中明确删除的候选形成 manual elimination；
- solver 仍只根据自己证明的候选状态推理；
- 推荐可以跳过已经由玩家明确完成的合法消除。

### 分支 B：正式棋盘唯一推荐输入（推荐）

- notes 完全不参与步骤选择；
- 每次提示返回当前正式棋盘的第一条逻辑步骤；
- 删除 `already_noted()` 与多 transition 跳过循环；
- 玩家只改笔记、不改正式数字时，再次提示允许重复同一消除步骤。

## 5. 验收标准

- [ ] 提示不调用 full solve 或 backtracking。
- [ ] GUI/Tk 相关门禁真实执行，不能由环境 skip 代替。
- [ ] README、ADR、codebase-design review 与最终代码行为一致。
- [ ] 没有新增远端、IO、子进程、DataFrame 或额外全量计算。

- [ ] screenshot import 初始不会制造 manual elimination。

- [ ] erase 清理对扩大后候选空间不再可靠的逻辑进度。

分支 B 追加：

- [ ] 同一 board 下任意 notes 内容都不改变推荐步骤。
- [ ] recommendation 最多请求一次 `next_step()`。
