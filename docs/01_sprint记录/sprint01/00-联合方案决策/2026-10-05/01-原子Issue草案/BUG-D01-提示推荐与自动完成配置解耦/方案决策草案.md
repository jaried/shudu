# BUG-D01 方案决策：提示始终使用全部算法并按现有笔记推理

- 状态：方案已决策，实施已提交，待本地回归验收
- 类型：BUG
- 优先级：P1
- GitHub Issue：不使用；docs Issue 为真源

## objective

自动解决菜单只决定“哪些算法自动执行”；提示固定拥有全部逻辑算法能力。

提示候选状态直接来自“正式棋盘 + 现有笔记”：

- 已有 notes 的格：以现有 notes 为候选；
- 没有 notes 的格：使用 solver 基础候选；
- 不要求生成整盘全部 notes。

## Module / Interface / Seam / Adapter

**Module**：`ShuduSolver`

**Interface**：`next_step() -> LogicStep | None`

固定使用全部算法，不读取自动配置。

**Module**：Hint

**Interface**：`make_hint(board, notes, wrong) -> Hint`

- 逐格投影现有 notes；
- 未记录 notes 的格保留基础候选；
- 只调用一次 `next_step()`。

**Seam**

`Game.hint() -> Hint -> ShuduSolver.next_step()`

**Adapter**

`sudoku_hint_view.py` 优先显示现有 notes；没有 notes 的相关格回退显示 solver candidate snapshot。
