# BUG-D01 方案决策：提示始终使用全部算法

- 状态：方案已决策，实施已提交，待本地回归验收
- 类型：BUG
- 优先级：P1
- GitHub Issue：不使用；docs Issue 为真源

## objective

自动解决菜单只决定“哪些算法自动执行”；提示固定拥有全部逻辑算法能力。

同时，提示必须正确理解当前候选状态：

- 完整 notes：作为当前候选状态输入 solver；
- 零散手工 notes：不作为 solver 约束。

这样同时满足：

1. Hidden Pair 未勾选也能被提示；
2. 已经从完整候选状态中删掉的候选不会被重复提示；
3. 某个候选只是“用户没写”时，不会被误判成“已逻辑删除”。

## Module / Interface / Seam / Adapter

**Module**：`ShuduSolver`

**Interface**：`next_step() -> LogicStep | None`

固定使用全部算法，不读取自动配置。

**Module**：Hint

**Interface**：`make_hint(board, notes, wrong) -> Hint`

- 完整 notes → 投影当前候选状态；
- 零散 notes → 不约束 solver；
- 只调用一次 `next_step()`。

**Seam**：

`Game.hint() -> Hint -> ShuduSolver.next_step()`

**Adapter**：

`sudoku_hint_view.py` 根据 Hint 决定显示现有完整候选还是 solver 候选快照。

## 验收

- [ ] Hidden Pair 未勾选时关卡 119 仍提示 Hidden Pair。
- [ ] auto_techniques 为空时同样成立。
- [ ] 完整候选已删除 7 时不重复提示删除 7。
- [ ] 零散 notes 不屏蔽 Hidden Pair。
- [ ] Hint 不读取 `auto_techniques`。
- [ ] Hint 只调用一次 `next_step()`。
- [ ] 自动执行仍只消费用户勾选集合。
- [ ] 不调用 full solve / backtracking。
