# 联合方案决策：提示推荐与自动完成配置解耦

- 状态：方案已决策，实施已提交，待本地回归验收
- 日期：2026-10-06
- 仓库：`jaried/shudu`
- 分支：`main`

## 1. 决策结论

1. 提示固定使用项目支持的全部逻辑算法，顺序保持：
   Hidden Single → Naked Single → Naked Pair → Hidden Pair → Naked Triple → Pointing Pair → Box-Line Reduction → X-Wing → XY-Wing。
2. `UserSettings.auto_techniques` 只控制自动执行，不裁剪提示算法集合。
3. 提示按**现有笔记逐格**建立当前候选状态：
   - 某个空格已有 notes：该格以现有 notes 为当前候选；
   - 某个空格没有 notes：该格继续使用 solver 根据正式棋盘得到的基础候选。
4. 不要求所有空格都有笔记，也不额外生成“全部笔记”后再提示。
5. Hint 只读，不修改 board、notes、history，不进入 full solve / backtracking。

## 2. 关卡 119 验收

正式棋盘：

```text
7183..459
6924..738
453879126
2...3.9..
...6...7.
5......82
.....7.4.
146583297
........3
```

必须满足：

- Hidden Pair 没有勾选自动执行时，提示仍可使用 Hidden Pair。
- 自动算法全部关闭时，提示仍使用全部提示算法。
- R6C2 现有笔记为 {3,6,7}、R6C7 为 {3,6} 时，可提示 Hidden Pair 删除 R6C2 的 7。
- R6C2 现有笔记已经是 {3,6} 时，该格候选状态不得重新补回 7。
- 其他没有笔记的空格继续使用基础候选，不要求先补齐整盘 notes。

## 3. Module → Interface → Seam → Adapter

### Module：ShuduSolver

**Interface**

`next_step() -> LogicStep | None`

合同：

- 固定扫描全部逻辑算法；
- 不读取 `auto_techniques`；
- 不读取 GUI；
- 不进入回溯。

### Module：Hint

**Interface**

`make_hint(board, notes, wrong) -> Hint`

内部语义：

1. wrong 优先返回错误提示；
2. 构造 `ShuduSolver(board)`；
3. 遍历**现有 notes 项**，仅对这些格把缺失候选投影为 solver 候选删除；
4. 未出现于 notes 的空格保持 solver 基础候选；
5. 调用一次 `next_step()`；
6. 将 `LogicStep` 适配为 `Hint`。

### Seam

```text
Game.hint()
  -> Hint Module
     -> project existing notes per cell
     -> ShuduSolver.next_step()
     -> LogicStep
     -> Hint
```

### Adapter

- `shudu/sudoku_hints.py`：LogicStep → Hint
- `shudu/sudoku_hint_view.py`：Hint → 只读视觉提示

View 对已有 notes 的格显示现有候选；相关区域中没有 notes 的格回退显示 solver 候选快照。

## 5. 防回归

- Hidden Pair 未勾选 + 现有局部 notes → 仍可提示 Hidden Pair。
- auto_techniques 为空 → Hint 仍使用全部算法。
- 现有 notes 中已经删除 R6C2 的 7 → 不重新补回 7。
- 没有 notes 的其他格继续保留基础候选。
- Hint 只请求一次全算法 `next_step()`。
- Hidden Pair 两个 source cell 保持绿色。
- 自动完成仍严格只执行用户勾选算法。
