# 联合方案决策：提示推荐与自动完成配置解耦

- 状态：方案已决策，实施已提交，待本地回归验收
- 日期：2026-10-06
- 仓库：`jaried/shudu`
- 分支：`main`

## 1. 决策结论

1. 提示固定使用项目支持的全部逻辑算法，顺序保持：
   Hidden Single → Naked Single → Naked Pair → Hidden Pair → Naked Triple → Pointing Pair → Box-Line Reduction → X-Wing → XY-Wing。
2. `UserSettings.auto_techniques` 只控制自动执行，不裁剪提示算法集合。
3. 完整候选笔记只表示“当前候选状态”。Hint 在构造 solver 后，把完整候选状态一次性投影到 solver，再调用一次 `next_step()`。
4. 零散手工笔记不作为 solver 求解约束，避免“没写某候选”被误认为“已经逻辑删除”。
5. 因此：
   - Hidden Pair 未勾选时，Hint 仍可以提示 Hidden Pair；
   - 已经在完整候选状态中删除的 7 不会被重新提示；
   - 不需要通过逐步 fast-forward 猜测哪些算法已经完成。
6. Hint 保持只读，不修改 board、notes、history，不进入 full solve / backtracking。

## 2. 关卡 119 验收

正式棋盘：

```text
7183..459
6924..738
453879126
2...3.9..
...6...7.
5......82
.....7.4.
146583297
........3
```

基础候选下：

- R6C2 = {3,6,7}
- R6C7 = {3,6}
- Hidden Pair 3/6 成立
- 当前动作是删除 R6C2 的 7

必须满足：

- Hidden Pair 没有勾选自动执行时，提示仍返回 Hidden Pair。
- 自动算法全部关闭时，提示仍返回 Hidden Pair。
- 完整候选状态若已经把 R6C2 的 7 删除，提示从这个候选状态继续，不重复删除 7。
- 零散 notes 例如只记录 R6C2={3,6}，不得因此屏蔽 Hidden Pair；这种 notes 不被视为完整候选状态。

## 3. Module → Interface → Seam → Adapter

### Module：ShuduSolver

**Interface**

`next_step() -> LogicStep | None`

合同：

- 固定扫描全部逻辑算法；
- 不读取 `auto_techniques`；
- 不读取 GUI；
- 不进入回溯。

### Module：Hint

**Interface**

`make_hint(board, notes, wrong) -> Hint`

内部语义：

1. wrong 优先返回错误提示；
2. 判断 notes 是否覆盖全部空格；
3. 若完整，则用 solver 的候选快照计算缺失候选，并调用 `apply_candidate_eliminations()` 投影当前候选状态；
4. 若零散，则不把 notes 注入 solver；
5. 只调用一次 `next_step()`；
6. 将 `LogicStep` 适配成 `Hint`。

### Seam

```text
Game.hint()
  -> Hint Module
     -> optional complete-candidate projection
     -> ShuduSolver.next_step()
     -> LogicStep
     -> Hint
```

### Adapter

- `shudu/sudoku_hints.py`：LogicStep → Hint
- `shudu/sudoku_hint_view.py`：Hint → 只读视觉提示

当 notes 是完整候选状态时，View 显示现有候选；当 notes 只是零散手工笔记时，相关提示区域显示 solver 候选快照，避免漏掉待解释候选。

## 5. 防回归

- Hidden Pair 未勾选 + 完整基础候选 → 仍提示 Hidden Pair。
- auto_techniques 为空 + 完整基础候选 → 仍提示 Hidden Pair。
- 完整候选已删除 R6C2 的 7 → 不重复该删除。
- 零散 notes 缺少 7 → 不得屏蔽 Hidden Pair。
- Hint 只请求一次全算法 `next_step()`。
- Hidden Pair 两个 source cell 保持绿色。
- 自动完成仍严格只执行用户勾选算法。
