### 事实

在实际仓库 `D:/Tony/Documents/invest2026/projects/shudu`、`Sprint01` 分支、HEAD `bdb144d948c5d4d9d26aca490ea10099477a8971` 上调用：

  issueId: "S1-02",
  artifactKind: "design",

```text

```

设计正式版本 helper 无法从其固定 locator 自动取得已提交 solution 版本；本票无法把该 helper 的失败误写成正常 publication 通过。设计语义、代码、测试和 tracker 范围保持可继续，本票使用实际 Git 事实和公开版本函数完成候选 metadata 材料化，并保留原始错误。
