## Depth、locality 与 deletion test

单步 Module 通过小 interface 隐藏 solver 构造、候选投影、一次技巧推进和完整步骤事实，形成 depth。Hint 不再理解候选消减或求解器状态组装；技巧身份与解释证据集中于求解目录，提高 locality。产品 Hint 和公开能力回归跨越同一 seam，结果作为既有 Hint adapter 的输入，形成 leverage。

删除单步内部实现会把 solver 构造和笔记语义放回 Hint 调用方；删除证据内部实现会把项目解释单位和执行前快照知识重新混入 adapter。复杂度会分散，收益不成立。当前 project / legacy 两种优先级仍有实际消费者；没有第二个单步算法实现 adapter，需要建立通用切换体系的依据不足。

日志文案仍保留历史呈现方式，步骤的技巧身份已明确携带，业务判断从结果读取身份。自动结果及差分工作处于已批准 S1-03 范围，继续沿该分工推进，候选列表为空。

## 实际执行面

错误数字由 make_hint 在单步请求前直接返回。有效提示创建一次 solver，投影当前 notes，调用一次 next_step，找到首个命中技巧即停止；输入棋盘和 notes 保持只读。无步骤按既有解释返回，不请求固定点或回溯。自动与 legacy 原路径不加载单步/项目证据模块。

执行面计数沿冻结设计与 ADR-002/003：候选转换、快照、finder、placement 和 [9,9] 输入规模不得增加；产品新增 IO、子进程及远端调用为零。此次扫描只核对已交付路径和证据，没有增加产品行为。
