## 矩阵与具体场景

Linux：批准的 Ubuntu 26.04/GNOME Wayland/XWayland、system CPython 3.14 / Tk 8.6.17 Xft、系统 Noto/DejaVu 和锁定依赖，普通/1.5/2 倍可容纳窗口/最大化、10 轮缩放恢复。读回桌面实际缩放、Tk scaling、像素密度和尺寸。Windows：批准 system-aware、100/125/150/200% 启动比例，同样窗口场景和同 DPI 显示器（有设备时）。不同 DPI 跨屏若用户改选范围，批准前重写本切片测试，不留现场裁量。

可达页面闭集包括 playing 正常/选格/笔记/暂停、Hint（短/长说明与滚动）、completed 完整棋盘、关卡菜单、设置与算法子菜单、截图导入成功/失败及错误弹窗。固定来源题和截图使用仓库现有 minimal fixture，保持原正式数字、候选、Puzzle/notes、错误结果和原 Game 引用断言；不替换原测试数据以规避生产链。

实际可见文本集合由 HOST/工具读取当前源码/运行菜单与页面生成，覆盖中文、数字、字母、·/→/✓/▶ 及实际其他符号。每个不同文字角色在实际 Tk 上读取 font actual/measure，仅作为字体选择与字形定位辅助；实际画面无方框、问号替代、转义或错乱字符由用户判读。游戏原本合法问号图标保留，不能把所有问号视为乱码。

原 Linux 乱码：先用历史环境或用户实际场景定位页面和字符，记录实际所见和复现条件；候选版本同位置核验正确文字。无法重现时明确“原乱码对照未完成”，保留原 AC2 为未完成，继续其他场景与前置票验证；不会凭广泛样本通过就宣布原问题已经解决。该未知是事实获取任务，不向用户提问是否降低原 AC。

缺失字体用可控公开 Tk seam 模拟分支并核验可见名称/回退/继续；实际桌面系统缺失场景可在已授权的独立环境验证，不删除宿主字体或影响其他应用。Q3 推荐提示条须在四类状态可见、关闭正常、最小 Canvas 区域保留；提示关闭仅原真实几何变化引发 resize，0 业务计算或配置写入。
