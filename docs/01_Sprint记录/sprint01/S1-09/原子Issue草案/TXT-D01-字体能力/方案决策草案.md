# TXT-D01：字体角色与缺失提示

状态：approval_draft；Q3 待裁决；批准后新登记 Issue。Parent：S1-09。Blocked by：无，可与 TXT-D02/03 并行。完整规格依据：[联合方案](../../../00-联合方案决策/2026-10-12/界面文字联合方案决策草案.md) 第 5～6、9～10 节；本切片独立完成同一请求文字→Tk 控件显示→缺失说明的能力链。

## 问题与交付结果

View 的两个 family 选择、Hint Text、GUI 菜单和 settings_menu 默认值存在分散知识，缺少时将 named font 当作 family。交付后，普通棋盘、候选、提示、菜单和设置统一按 ui/number 角色取得合法字体；首选缺失名称可见，回退后游戏保持可用。字体提示独立于 Game.message，覆盖普通、Hint、暂停和完成页。

## 冻结的 Module、接口与 owner

TextFonts 属呈现层，目录 `shudu/text_fonts/`。唯一公开 import 入口 `__init__.py`；internal `_selection.py` 集中角色/匹配，`_specs.py` 解析 named font 与构造元组。

公开能力：`TextFonts(master).spec(role,signed_size,weight='normal') -> tuple[str,int,str]`，只读 `missing_preferred: tuple[str,...]`；`system_font(master,signed_size=11) -> tuple[str,int,str]`。role 闭集 ui/number，weight normal/bold，size 非零有符号整数；非法输入 ValueError。同 Window/View 一次初始化，枚举 family 一次，保存两个角色，逐帧 spec 无 Tk 查询。无副本 Font、size cache、全局 root 引用或生产逐字符探测。

Windows ui 候选 Microsoft YaHei UI、Microsoft YaHei、PingFang SC、Noto Sans CJK SC；number 为 Segoe UI Light、Helvetica Neue、DejaVu Sans。Linux ui 为 Noto Sans CJK SC，number 为 DejaVu Sans。大小写无关匹配并使用 Tk 返回实际名称；首项不可见即记录首选名称。全部不可见时解析 `font actual TkDefaultFont -displayof <master> -family`，把真实 family 放入元组。Tk 提供逐字符系统回退，逐字符真实效果由测试验收。

View 创建和持有唯一 TextFonts，新增公开 `font(role,signed_size,weight='normal')`，其 text 请求角色并保持原负像素计算。Hint 的 Canvas 文字沿用 View；description_text 用 View.font 的 ui 角色，保留原负像素计算。GUI _menu/show_settings 显式请求 ui +11 点。settings_menu.open_settings 省略 font 时独立 system_font 解析 +11 点；Popup 内部从 public 入口接收已解析的值，默认错误元组退出。显式 font 路径保持现值并零枚举，standalone 默认路径一次实际 family 查询、零枚举。

调用方只知道 role、signed_size、weight，Font Module 不访问 Game、solver、截图或 Store。Hint→View 和 settings_menu 的现有公开入口继续作为高层 Seam。Tk 查询细节藏于 Adapter/internal；不扩散平台字体名单。

## 提示条推荐分支及资源

Q3 选择推荐时，Window.__init__ 在 Canvas 外上方创建非模态提示条，只在 missing_preferred 非空出现。固定文案：“当前 Tk 未识别首选字体：<去重名称>。已使用系统回退字体，可继续游戏。”，附“关闭字体提示”。提示用 ui 字体并换行，button 可键盘操作；不获取 grab、不抢焦点。

提示覆盖所有游戏页面；关闭后本次进程保持关闭，下次启动检测。显示期间 root 最小高度为 613 加提示条实际请求高度，保留原 Canvas 最小可用区域；关闭恢复原最小尺寸。控件生命周期属于 Window.close。提示没有独立 timer、偏好项、字体热更新或自动安装。显示/关闭只改控件和真实几何；因实际 Canvas 尺寸改变而触发原 Configure 重绘，主动 View.draw、业务求解、Store、Game.message 写入均为 0。

如 Q3 改选设置中的状态入口，最终批准前替换本节及 Items/测试/布局，保持缺失继续游戏和状态隔离；实施阶段只执行唯一最终分支。
