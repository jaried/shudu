# iOS 数独双向同步预研

预研日期：2026-10-07。目标是在电脑上的现有 Shudu 中手动操作、按指定算法自动求解、一键笔记和查看提示，并将操作应用到 iOS 数独 App；手机手动填数、擦除或修改笔记后，电脑自动同步同一局的状态。

用户条件：软件免费，当前没有开发者账号，完全没有 Mac；Windows 10 与 Ubuntu 26 均为候选。目标 App 已选定，具体名称、手机型号及 iOS 版本尚待补充。
