# 图形化数独游戏

## 任务与状态

依据用户提供的三张关卡 108 截图，利用 `shudu` 现有代码实现可运行桌面数独。状态：已实施，新增测试通过，待用户实机验收。

基于 `main` 的 `cd722311f2e8c53f11a25f5c0c8982c765fdc0a4` 实施。采用增量新增文件，不修改既有求解器、逻辑演示、技术说明或既有测试。

## 实施决策

1. 采用 Tkinter Canvas，统一缩放、绘制和点击命中坐标，不引入额外 GUI 框架。
2. `sudoku_game.py` 管理独立游戏状态，答案复用 `DEFAULT_BACKTRACKING_SOLVER`；题面载入时求解并缓存，交互时不搜索。
3. 按第三张截图录入 24 个已知数；第一、二张截图的手工笔记和错误值不作为原题给定。
4. 按截图实现选中、行列宫关联、同值数字与笔记、高亮优先级、错误累计及笔记开关。
5. 撤回恢复数字和相关笔记，但不退回错误或提示次数；第三次错误终局；提示明确为答案填一格。
6. 内置三个固定唯一解题目。本次不加入随机出题、文件导入、自动存档、广告或网络功能。
