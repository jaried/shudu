# 图形化数独游戏

## 任务与状态

依据用户提供的关卡 108 截图实现桌面数独，并在后续反馈中连续完善高亮、只读提示与候选笔记。状态：已实施并通过自动化测试，待 Windows 实机视觉验收。

## 当前行为

1. 采用 Tkinter Canvas；棋盘、控件、鼠标命中使用统一逻辑坐标与等比缩放。
2. 题面答案继续复用 `DEFAULT_BACKTRACKING_SOLVER`；提示复用 `LogicSolver` 的既有逻辑技巧，不新增另一套求解算法。
3. 选中已确定大数字时，同值大数字及它们各自所在的行、列、宫全部高亮；同值小数字笔记也高亮，即使笔记开关关闭。
4. 提示仅展示 `LogicSolver` 的下一步推理与相关区域，不自动填大数字，不修改玩家笔记；错误盘面先要求修正。
5. 自动笔记一键重算全部空格的行、列、宫合法候选，只写小数字，可整步撤回。
6. 错误数字继续标红并累计次数。错误次数不设上限，不会触发失败终局；重复点击当前同一错误值不重复计数，擦除和撤回不退错误次数。
7. 只有完整正确填完棋盘才进入完成状态；暂停与提示期间停止计时。
