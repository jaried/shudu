# shudu · 数独

基于现有 Python 数独求解器的桌面游戏。默认载入用户截图中的 **关卡 108**，保留奶油色背景、橙棕色数字、关联区域高亮、同数字绿色高亮和九宫格候选笔记。

## 启动

在仓库目录下，使用准备运行游戏的 Python 环境执行：

```bash
python -m pip install -r requirements.txt
python sudoku_gui.py
```

建议使用 Python 3.12。代码要求 Python 3.10 或更新版本，运行环境需要 `tkinter`；可先执行 `python -m tkinter` 检查是否能打开测试窗口。Windows 的 Python 安装应包含 Tcl/Tk 组件。Linux 缺少该组件时需安装与所用 Python 环境匹配的 Tk 支持，例如系统 Python 的 `python3-tk` 包。

首次运行公共求解器会有 Numba 编译开销。求解只发生在载入题目时，计时从题目就绪后开始；填写数字、点击和重绘不执行搜索。

Windows 配好同一 Python 环境后，也可双击 `run_gui.bat`。游戏完全在本地运行，不需要网络或账号。

## 截图对应的交互

| 操作或状态 | 实际行为 |
| --- | --- |
| 选择空格 | 当前格橙色，同行、同列、同宫浅色高亮 |
| 选择已有数字 | 当前格棕底白字，其他相同数字绿底白字；笔记模式下的同值笔记也变绿 |
| 笔记开关打开 | 数字作为 3×3 小字标记；再次输入同一数字取消标记，不正式填数、不记错误 |
| 笔记开关关闭 | 数字正式填入；题目已知数不可修改 |
| 填写错误 | 错误格显示红底；行、列、宫中的关联冲突数字显示橙红色；错误次数增加 |
| 无重复但答案错误 | 仍会标记错误；校验依据原始题目的唯一解 |
| 正确填数 | 清除本格笔记，默认清理同行、同列、同宫的同值笔记；设置中可关闭自动清理 |
| 擦除、撤回 | 擦除正式数字或整格笔记；撤回恢复该步之前的数字及关联笔记 |
| 暂停 | 隐藏棋盘、暂停计时并禁止操作；继续后恢复 |
| 提示 | 根据原题求解结果填写一格，不受当前错误值或手工笔记影响 |

同一个错误值连续重复点击只记一次错误；改变为另一个错误值会再记一次。擦除、撤回不退回累计错误。达到 **3 次错误** 后本局结束，可重新开始或换关卡。提示次数同样累计，不因撤回减少。

提示是“一次填一格答案”，不是现有逻辑求解器的逐步推理讲解。笔记允许手动标记任意 1–9，不会擅自限制为程序计算的候选集合。

## 键盘

| 按键 | 功能 |
| --- | --- |
| `1–9` / 数字小键盘 | 根据笔记开关，填写数字或切换标记 |
| 方向键 | 移动选中格 |
| `N` | 切换笔记模式 |
| `Delete` / `Backspace` / `0` | 擦除 |
| `Ctrl+Z` | 撤回 |
| `H` | 提示一格 |
| 空格 / `Esc` | 暂停或继续 |

某数字已在九个正确位置填满后，普通输入模式会禁用该数字；笔记模式仍可增删相应标记。已知数或已有正式数字不能直接添加笔记，需要先擦除可编辑的正式数字。

## 关卡与边界

左上角返回形状按钮打开关卡菜单，右上角齿轮打开设置。内置三个固定且已验证唯一解的题目：截图关卡 108、入门练习、复用 `solver.py` 原题的回溯挑战。切换关卡或重开已有进度的游戏会先确认。

当前版本不包含随机出题、题面导入、自动存档或广告。关闭窗口不会保存当前进度。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `sudoku_gui.py` | 启动入口、菜单、键盘和操作分发 |
| `sudoku_view.py` | 棋盘、笔记、工具按钮、高亮、错误和暂停画面 |
| `sudoku_game.py` | 游戏状态、原题答案缓存、笔记、撤回、计时与胜负 |
| `sudoku_puzzles.py` | 严格校验的内置题面 |
| `sudoku_backtracking.py` | **既有公共求解器，保持原样并直接复用** |
| `solver.py` / `logical_solver.py` / `techniques.py` | 既有求解及演示入口，保持原样 |

图形层使用 Tkinter，没有额外引入 Qt、Web 服务或另一套数独搜索算法。关于 Tk 安装与线程模型可参见 [Python 官方文档](https://docs.python.org/3/library/tkinter.html)。

## 测试

安装测试依赖后，在仓库根目录执行：

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

有桌面显示环境时包含真实 Tk 交互测试；无显示的 Linux 会跳过 GUI 测试。使用虚拟显示执行全部新增测试：

```bash
xvfb-run -a -s "-screen 0 1400x1200x24" python -m pytest tests -q
```

2026-09-13 验证结果：**58 项新增测试通过**，其中 44 项为题面、求解与状态测试，14 项为真实窗口交互测试。环境为 Linux、Python 3.13.5、Tk 8.6、NumPy 2.3.5、Numba 0.65.1。原有逻辑求解测试未包含在这 58 项中；未宣称已完成其全量回归。

测试覆盖三题唯一解、原题不变性、笔记切换、已知数保护、错误累计、关联冲突、擦除和撤回、笔记恢复、提示、暂停计时、胜负锁定，以及缩放后的鼠标命中、键盘操作和着色。Windows 实机上的字体、缩放和双击入口仍待人工验收。具体复现步骤见 [GUI 验收说明](docs/gui-acceptance.md)。
